Sistema de Gestión de Gimnasio

Descripción
Este proyecto consiste en una base de datos relacional creada para administrar las operaciones diarias del gimnasio. Organiza la información en tablas dedicadas a clientes, membresías, pagos, instructores, clases, rutinas y ejercicios.

Justificación
Debido a un aumento repentino de socios, el registro tradicional en libretas de papel dejó de ser práctico. Se necesitaban demasiados minutos para buscar la ficha de una persona o revisar quién había pagado. La base de datos resuelve este problema al pasar todo a un sistema digital estructurado.

Beneficios

Permite buscar al instante los datos de cualquier cliente, sus horarios y su rutina de entrenamiento.

Facilita el control de las cuotas al día, los pagos del mes y el tipo de plan contratado.

Ayuda a gestionar la disponibilidad de los instructores ante cualquier imprevisto o cambio de turno.

Mejora la atención a los clientes y agiliza el trabajo diario en la recepción.

Objetivos

Reemplazar los registros en papel por una base de datos centralizada.

Mantener organizada la información de socios, pagos y rutinas.

Reducir el tiempo necesario para consultar o modificar la información del gimnasio.
